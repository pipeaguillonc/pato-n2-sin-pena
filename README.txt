PATO Odor Block - Mision N2 sin Pena: landing + juego (PWA)

CONTENIDO
- index.html ............ landing
- jugar.html ............ el juego (9:16)
- manifest.webmanifest, sw.js, icon-192.png, icon-512.png ... para instalarlo como app

PUBLICAR (gratis, 2 minutos)
1. Entra a https://app.netlify.com/drop
2. Arrastra ESTA CARPETA completa. Te da un enlace https.
   (Tambien sirve Vercel, GitHub Pages o el hosting de la agencia.)

INSTALAR EN TABLET (sin APK)
- Android/Chrome: abre el enlace > menu > "Instalar app" / "Agregar a pantalla de inicio".
- iPad/Safari: Compartir > "Agregar a inicio".
Abre a pantalla completa y, despues de la primera carga, funciona sin internet.

SACAR UN APK
1. Entra a https://www.pwabuilder.com y pega el enlace publicado.
2. "Package for stores" > Android > Generate. Descargas un .zip con el .apk.
3. En la tablet: permite "instalar apps de origenes desconocidos" e instala el .apk.
